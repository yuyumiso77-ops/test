# FJ 매출 현황 대시보드

판매정보현황 엑셀을 합산해 매장·일자·상품별 매출을 보여주는 대시보드입니다. Railway 같은 Node 호스팅에 그대로 올려 실행할 수 있습니다.

현재 데이터: 2026년 11월 1–21일, 91개 매장, POS 판매 31,605줄 (순매출 46.53억원, 확정금액 38.20억원, 수량 24,789개).

## 화면 구성

맨 위 필터(유통 형태, 매장)는 세 탭 모두에 적용됩니다.

- **연간 리포트**: 올해 누계·연간 예상(전년 대비), 월별 막대(작년 같은 달), 분기·반기 실적, 유통사별 연간 누계, 매장별 연간 순위(성장·하락 상위), 상품 구성(라인·아이템·성별·판매형태, 다 끝난 달 기준), 회원 연간(회원 비중·신규 가입 추이)
- **월별**: 월 상세(월을 골라 지표·일별·유통사·아이템·매장 순위·상품 베스트), 월별 실적표, 월별 지표 추이(객단가·영수증·할인율·반품률, 올해 vs 작년), 월별 회원·남성·정상가 비중, 유통사·아이템·매장 월별 상세표
- **당월**: 핵심 지표, 어제 실적 브리핑, 일별 매출(전년 같은 요일), 월 마감 예상, 일별 실적표, 목표 대비, 주별, 회원·비회원, 남성·여성, 매장별, 유통사별, 유통 형태·판매 형태·라인·아이템, 상품, 시간대

## 실행

```bash
npm start
```

Node 18 이상에서 `npm install` 후 실행합니다 (엑셀 읽기용 exceljs). 포트는 `PORT` 환경 변수(기본 3000)를 따릅니다.

### 비밀번호

처음 접속하면 비밀번호 화면이 나오고, 맞게 입력해야 대시보드와 데이터 파일이 열립니다. 한 번 들어가면 30일 동안 다시 묻지 않습니다 (`/logout`으로 나가기).
- 기본 비밀번호는 `server.js`에 들어 있습니다. 이 저장소는 공개이므로, 바꾸려면 Railway **Variables**에 `DASHBOARD_PASSWORD`를 넣으세요. 환경 변수가 기본값보다 우선합니다.
- 같은 주소에서 10분 안에 10번 틀리면 10분 동안 막힙니다.

## 데이터 갱신

### 사이트에서 올리기 (매일 아침)

1. ERP에서 **판매정보현황 엑셀(이번 달 1일부터 어제까지)** 을 내려받습니다.
2. 대시보드 위쪽의 **자료 올리기**(`/upload`)에서 파일을 끌어다 놓고 **올리고 대시보드 갱신**을 누릅니다.
3. 서버가 엑셀을 합산해(30초 안팎) 대시보드를 바로 바꿉니다. 대시보드 위쪽에 자료 기간과 갱신 시각이 나옵니다.

원본 엑셀과 고객번호는 저장하지 않고 합계 CSV만 저장합니다.

새 달 자료(예: 12월 1일 자료)를 처음 올리면, 그전까지 쓰던 달(11월) 자료가 월별 기록(`hist_store_daily.csv`, `month_item.csv`)에 자동으로 옮겨집니다. 그래서 매달 마지막 날까지의 자료를 꼭 한 번 올린 뒤 다음 달로 넘어가 주세요.

### Railway 저장 공간(Volume) — 꼭 연결

올린 자료는 Volume에 저장됩니다. Volume이 없으면 사이트가 다시 배포될 때 올린 자료가 사라지고 저장소의 기본 자료(`public/data`)로 돌아갑니다.
서비스에 Volume을 붙이면 Railway가 `RAILWAY_VOLUME_MOUNT_PATH`를 넣어 주므로 따로 설정할 것은 없습니다 (직접 정하려면 `DATA_DIR`).

### 자동 전송 (24시간 컴퓨터 등)

Railway **Variables**에 `UPLOAD_KEY`(길고 추측하기 어려운 값)를 넣으면, 그 값을 헤더에 실은 요청은 로그인 없이 올릴 수 있습니다.

```bash
curl -X POST -H "X-Upload-Key: <UPLOAD_KEY 값>" -H "X-File-Name: sales.xlsx" --data-binary @판매정보현황.xlsx https://<사이트 주소>/api/upload
```

### 명령줄로 합산만 하기

```bash
npm install
```

```bash
node aggregate.js 판매정보현황.xlsx public/data
```

`scripts/*.py`는 같은 합산을 하는 이전 파이썬 버전입니다.

## 계산 방식

- 순매출 = 판매금액 합계 (반품은 음수로 들어 있어 자동으로 빠짐)
- 객단가 = 판매 줄의 판매금액 ÷ 판매 영수증 수 (영수증 = 일자·매장·판매번호)
- 평균 할인율 = 1 − 순매출 ÷ (TAG가 × 수량)
- 회원 = 고객번호가 있는 판매, 비회원 = 없는 판매
- 신규 가입 = 고객번호가 자료의 마지막 달(F + 연월) 번호인 회원 수 (처음 구매한 날·매장에 한 번만 셈)
- 유통사 = 매장 이름(롯데·현대·신세계·갤러리아·AK) + 백화점/아울렛. 베스트·워스트 비교에서 사용중지 매장과 순매출 0 이하 매장은 제외
- 유통 형태 = 매장코드 첫 글자: C 백화점, D 아울렛, B 가두점, A 기타
